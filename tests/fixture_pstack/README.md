# pstack fixture

`pstack-sample.log` is a trimmed, sanitised excerpt of a real 2015 customer capture on MarkLogic on EC2: 4 snapshots, 61 of 582 threads kept, and deep stacks cut to the first 12 and last 6 frames. Counts therefore differ from the full capture. It contains no customer, host or company names, and the original is not kept in this repository.
