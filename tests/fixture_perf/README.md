# perf fixture

`perf-report-sample.txt` is a trimmed, sanitised excerpt of a real 2015 customer capture on MarkLogic on EC2: the report header plus the first 60 top-level entries, with the call-graph lines trimmed to at most 8 per entry. Counts therefore differ from the full capture. It contains no customer, host or company names, and the original is not kept in this repository.
